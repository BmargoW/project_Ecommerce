# Ядро для интернет-магазина

## Описание:

В этом проекте проработано использование классов и объектов. 
В нем Созданы классы Product и Category
Для удобства работы с продуктами реализована возможность их складывать
Можно складывать товары только из одинаковых классов продуктов
## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/BmargoW/project_Ecommerce
```
1. Установите зависимости:

```poetry init```

## Тестирование:
В проекте используются тесты используемых функций. Для их запуска необходимо 
выполнить команду 
``` pytest```

## Использование:

1. Клонируйте проект на Github.
2. Откройте проект и начните добавлять задачи.
